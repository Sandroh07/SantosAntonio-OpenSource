# Contributing

Thank you for helping make business software more accessible. This is an MIT-licensed portfolio and everyone can submit issues, bug fixes, tests, documentation improvements and new translations.

1. Create a focused branch and describe the business use case.
2. Use **English** for code comments, README and pull request descriptions where practical.
3. Include tests when changing financial logic, inventory calculations or petroleum conversions.
4. Do not post personal information, client transactions, `.env` files, API keys or credentials.
5. Never claim AGT tax certification, oil measurement approval, or statutory compliance without independent formal evidence.
6. Keep the voluntary donation section visible; never build paywalls into core open-source features.

Licensed contributions to this repository are accepted under the MIT license; please confirm you are entitled to contribute the code.
